Set it up

About 2 minutes, in Google Chrome. You only do this once.

  1. Open this page in Google Chrome. If the link opened in Safari or another browser, copy the address from the address bar, open Chrome, paste it into Chrome's address bar and press Enter.
  2. Show your bookmarks bar. Press Cmd + Shift + B on a Mac, or Ctrl + Shift + B on Windows. A thin bar appears just under Chrome's address bar. The same keys hide it again, so press them once.
  3. Only if you set up R lookup before: remove the old ones. On your bookmarks bar, right-click each old one (Agent UI, Wsheet, Wira, Tarro Manager, Restaurant Config) and choose Delete.
  4. Drag each bookmark you want onto your bar. In the picture at the top of this page, press and hold a bookmark (for example Wsheet), move it up onto your own bookmarks bar, and let go. It appears on your bar with the same name. Repeat for the others.
  5. Try it. Open a new tab (Cmd + T), click Wsheet on your bar, and type 85791. The Wsheet for R85791 opens by itself.

Using it

  • Click a bookmark on any tab, even a new one. A box appears with the R already filled in. Type the 5 digits and the page opens. No Enter needed.
  • To keep the page you're on, hold Cmd + Shift (Ctrl + Shift on Windows) while you click the bookmark. It opens in a new tab.
  • You can paste instead of typing: a link, or text like NEW CHINA (R82788). It picks out the R number.
  • Shorter number? Type it and press Enter. Changed your mind? Press Esc.

If something doesn't work

  • Clicking a bookmark on this page doesn't open anything. That's expected: here it only shows a preview. Drag it onto your bar and use it from there.
  • What you type goes into the address bar, not the box. Click once anywhere on the box's page, then type.
  • A bookmark won't drag. Add it by hand instead: see Can't drag? at the bottom of this page.
  • You land on a sign-in page. Sign in to Greendot or Tarro Manager in Chrome. The bookmark only takes you to the page.
  • The R number has 6 digits. Paste it. Typing opens the page as soon as 5 digits are in.

Prefer the keyboard? Address-bar shortcuts

Instead of clicking a bookmark, type a short code in Chrome's address bar. This one needs Enter, but it works from any tab without the bookmarks.

Set it up once (about 2 minutes)

  1. Open Chrome's search settings. Click Copy, click Chrome's address bar, paste, and press Enter.
  2. Scroll down to "Site search" and click Add next to it. A small box opens with three fields.
  3. Fill in the three fields from one row below, then click Add. Name: type the name. Shortcut: type the shortcut. URL with %s in place of query: click the row's Copy button and paste.
  4. Repeat step 3 for each one you want.

Use it

Press Cmd + T, type the shortcut (for example ws) and press Space. The address bar switches to that site. Type the 5 digits and press Enter. Type only the digits: the R is already in the URL.

Can't drag? Add a bookmark by hand
  1. Click Copy next to the one you want below.
  2. Right-click your bookmarks bar and choose "Add page…".
  3. Fill in the box and save. Name: type the bookmark's name (for example Wsheet). URL: delete what's there and paste. Click Save.
